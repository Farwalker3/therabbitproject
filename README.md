# The Rabbit Project — Revival

Let's Revive the Rabbit Project.

**The Rabbit Project** (rabbit.game) was an abandoned play-to-earn idle game
about NFT rabbits grinding dungeons for $CARROT. This repo revives it as a
**story and TV series**.

- **`index.html`** — the revival site: recovered game canon, the five in-game
  locations reimagined as standing sets, the series treatment (logline, cast,
  season one), The Rabbit's Club partnership pitch, the archive of what
  survived, and the revival roadmap. Fully self-contained (no build step);
  works as a GitHub Pages root.
- **`research/RESEARCH.md`** — the recovery dossier: everything recoverable
  about the original game — mechanics, hard facts (Sei blockchain,
  @RabbitsOnSei, token), recovered artwork — plus The Rabbit's Club partner
  dossier and leads for a deeper dig.
- **`archive/`** — complete saved copies of the two surviving listings
  (ChainPlay and CryptoGames), assets and all.
- **`assets/`** — the recovered original artwork: banner, crossed
  carrot-and-sword emblem, marks, and a Rabbit's Club art sample.

## The premise

The game's real fate is the story: a world of working rabbits built to grind
forever — whose players quietly vanished. The servers idled on. Nobody was
watching. Season one asks what a world does when everyone logs off.
